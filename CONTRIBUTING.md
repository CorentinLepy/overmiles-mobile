# Contribuer

1. Partir de `main` à jour.
2. Créer une branche `cor-XX-description`.
3. Ne modifier qu’un périmètre Linear cohérent.
4. Exécuter `pnpm verify` avant tout push.
5. Ouvrir une PR en Draft avec risques, tests et stratégie de rollback.
6. Ne jamais contourner les garde-fous TLS, secrets, stockage sécurisé ou séparation des environnements.
